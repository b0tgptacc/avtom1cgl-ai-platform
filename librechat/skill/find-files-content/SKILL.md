# Поиск файлов по содержимому

Ты **не видишь компьютер пользователя** и не подключаешься к нему. Поиск запускает сам пользователь у себя —
готовым проверенным скриптом `Find-TextInFiles.ps1` из этого навыка (он только читает файлы, ничего не меняет,
ничего не устанавливает и ничего не отправляет в сеть). **Свои скрипты для компьютера пользователя не пиши** —
только этот, меняются лишь параметры команды.

Если из вопроса неясно — уточнить одним сообщением: где искать (папка, диск, сетевая папка; по умолчанию — вся
папка пользователя), что искать (слова, номер, фраза), нужны ли только файлы, где есть все слова сразу.

## Скрипт Find-TextInFiles.ps1

Читает: Word (docx, doc), Excel (xlsx, xls), PowerPoint (pptx, ppt), OpenDocument (odt, ods), RTF, txt/csv/log/xml/
json/md/ini/sql в UTF-8 и Windows-1251; в том числе файлы, открытые сейчас в Word/Excel. Пропускает AppData,
корзину, системные папки, временные `~$`-файлы. **PDF не читает** — сообщает, сколько PDF в папках (см. ниже).

### Как передать скрипт пользователю

**Стенд агентов** (у тебя есть папка `outbox`): скопируй скрипт из папки навыка в `outbox` и дай ссылку.
```bash
cp "$(find /skills -name Find-TextInFiles.ps1 -path '*find-files-content*' | head -1)" outbox/Find-TextInFiles.ps1
```
Ссылка: `[Find-TextInFiles.ps1](/agent-files/<движок>/Find-TextInFiles.ps1)`. Браузер сохранит файл в «Загрузки»
(имя может получить приписку, например `Find-TextInFiles (Hermes).ps1`) — команда ниже находит его сама.

**Обычный чат** (без папки `outbox`): скрипт выдаёт ИТ-отдел; содержимое скрипта в ответ не вставлять.

### Команда для пользователя

Пользователь открывает «Windows PowerShell» (Пуск → ввести `powershell` → Enter) и вставляет команду целиком.
Подставь папку и слова; остальное не меняй:
```powershell
Set-ExecutionPolicy -Scope Process Bypass -Force
$s = (Get-ChildItem "$env:USERPROFILE\Downloads\Find-TextInFiles*.ps1" | Sort-Object LastWriteTime | Select-Object -Last 1).FullName
& $s -Path "D:\Документы" -Pattern "Ромашка,7707083893"
```
Первая строка разрешает запуск скриптов только в этом окне (права администратора не нужны).

Параметры:
| Параметр | Что делает | Пример |
|---|---|---|
| `-Path` | где искать, с подпапками; несколько — через запятую; без него — вся папка пользователя | `"D:\Документы,\\server\share\Договоры"` |
| `-Pattern` | слова/фразы через запятую; регистр не важен, «е» находит и «ё» | `"Ромашка,7707083893"` |
| `*` в конце слова | любое окончание | `"договор* поставки"` → договора поставки, договору поставки |
| `-All` | только файлы, где есть **все** слова (по умолчанию — любое) | |
| `-Include` | только эти типы файлов | `-Include docx,doc` |
| `-Regex` | слово — регулярное выражение (запятая тогда не разделяет) | `-Pattern '\b\d{10}\b' -Regex` |
| `-MaxSizeMB` | файлы больше этого размера пропускаются (по умолчанию 50) | `-MaxSizeMB 200` |
| `-OutCsv` | куда сохранить список (по умолчанию `Поиск_<дата>.csv` на рабочем столе) | |

Что увидит пользователь: число просмотренных и найденных файлов, таблицу «Файл, Слова, Совпадений, Фрагмент»,
путь к CSV на рабочем столе (открывается в Excel двойным щелчком; столбцы: Файл, Тип, Изменён, Размер, Слова,
Совпадений, Фрагмент — текст вокруг первого совпадения). Журнал: `%LOCALAPPDATA%\Find-TextInFiles.log`.

### Разбор результата

Если пользователь прикрепил CSV `Поиск_….csv` — прочитай его (разделитель `;`, UTF-8 с BOM) и помоги: сгруппировать
по папкам или контрагентам, отобрать по дате, найти дубликаты, составить список для письма; большой результат —
файлом Excel. Фрагменты могут содержать персональные данные — в ответе приводи только то, что нужно для задачи.

### Частые ошибки
- «выполнение сценариев отключено» и после первой строки команды — запуск запрещён политикой компании, обратиться в ИТ.
- «Get-ChildItem: не удаётся найти путь …Downloads…» — скрипт не скачан или сохранён в другую папку: указать путь
  к нему вместо `$s`, например `& "D:\Скрипты\Find-TextInFiles.ps1" -Path ...`.
- «Не прочитаны (повреждены или защищены паролем)» — список таких файлов в журнале; открыть их вручную.
- «PDF в папках: N» — PDF скрипт не читает: Проводник → поле поиска → `содержимое:слово` (способ 1), Adobe Reader
  (Shift+Ctrl+F → «Все PDF-документы в» → папка) или прикрепить нужные PDF в чат и попросить найти в них.

## Полезные регулярные выражения для -Regex
| Что найти | Выражение |
|---|---|
| ИНН организации (10 цифр) | `\b\d{10}\b` |
| ИНН физлица / ИП (12 цифр) | `\b\d{12}\b` |
| Номер телефона | `(\+7|8)[\s(-]*\d{3}[\s)-]*\d{3}[\s-]*\d{2}[\s-]*\d{2}` |
| Номер договора вида «№ 15/2026» | `№\s*\d+/\d{4}` |
| E-mail домена компании | `[\w.-]+@romashka\.ru` |
Регулярное выражение вводить в одинарных кавычках: `-Pattern '\b\d{10}\b' -Regex`.

## Без скрипта

| Ситуация | Способ |
|---|---|
| Поиск по **имени** файла | Проводник: в поле поиска `имя:договор` или `*.xlsx`; или программа Everything (мгновенно по всему диску) |
| Одна небольшая папка, нужен быстрый ответ, PDF | Поиск Windows (способ 1) |
| Только PDF | Adobe Reader: Shift+Ctrl+F → «Все PDF-документы в» → папка |

### Способ 1. Поиск Windows (Проводник)
1. Открыть папку, в которой искать, щёлкнуть в поле поиска справа вверху.
2. Ввести `содержимое:Ромашка` (если не срабатывает — `content:Ромашка`, работает в любой языковой версии). Фраза — в кавычках: `содержимое:"договор поставки"`.
3. Если результатов нет, а файлы точно есть: Поиск → Дополнительные параметры → «Содержимое файлов» (галочка) —
   тогда ищет и в неиндексированных папках (медленнее). Для постоянной работы — добавить папку в индекс:
   Пуск → «Параметры индексирования» → Изменить → отметить папку.
4. Фильтры: `тип:docx`, `изменён:прошлая неделя`, `размер:>1МБ`, можно сочетать: `содержимое:Ромашка тип:xlsx`.

### Способ 2. Total Commander (если установлен)
Alt+F7 → «Искать файлы»: `*.*`, отметить «С текстом», ввести слово, отметить кодировки «ANSI» и «UTF-8».
Найденное — кнопка «Файлы на панель». Для docx/xlsx/pdf нужны плагины содержимого.

## Безопасность
Если пользователь ищет файлы с персональными данными (паспорта, СНИЛС) — напомнить, что найденные файлы
нельзя пересылать и выкладывать в общие папки без необходимости, а результат (CSV) удалить после работы.

# Объединение и группировка таблиц Excel

Сначала уточнить (одним сообщением, если не ясно из запроса):
1. Сколько файлов/листов и где они (одна папка? одна книга?).
2. Одинаковые ли у них столбцы (названия и порядок).
3. Что получить: просто одна общая таблица / итоги по группам (по контрагенту, месяцу, складу…) / сравнение двух списков.
4. Версия Excel: 365 / 2021 / 2016–2019 (от неё зависит, доступны ли новые функции).

Выбор способа:
| Задача | Способ |
|---|---|
| Много файлов с одинаковыми столбцами, повторяется каждый месяц | **Power Query «Из папки»** (способ 1) — один раз настроить, дальше «Обновить» |
| Несколько листов одной книги | Power Query «Добавить запросы» (способ 2) |
| Итоги по группам из одной таблицы | Сводная таблица (способ 3) или СУММЕСЛИМН / GROUPBY (способ 4) |
| Подтянуть данные из другой таблицы, найти расхождения | ПРОСМОТРX / ВПР (способ 5) |
| 2–5 небольших таблиц (до нескольких сотен строк), разово | Вставить таблицы в чат — агент объединит и вернёт готовую таблицу (способ 6) |

## Перед объединением — проверить данные
- Заголовки одинаковые во всех файлах (одинаковое написание, без лишних пробелов, одна строка заголовка).
- Нет объединённых ячеек, пустых строк и строк «Итого» внутри данных (их убрать или отфильтровать).
- Числа — числа, а не текст (зелёный треугольник в углу ячейки): выделить → значок «!» → «Преобразовать в число».
- Даты — даты (выравнивание по правому краю). Даты-текст из 1С: Данные → «Текст по столбцам» → Далее → Далее → формат «Дата ДМГ».
- Лишние пробелы в названиях: `=СЖПРОБЕЛЫ(A2)`; неразрывные пробелы из 1С: `=ПОДСТАВИТЬ(A2;СИМВОЛ(160);" ")`.

## Способ 1. Power Query: все файлы из папки (Excel 2016+)
1. Сложить все файлы в одну папку (только нужные, одинаковой структуры).
2. Новая книга → **Данные → Получить данные → Из файла → Из папки** → выбрать папку → **Объединить → Объединить и преобразовать данные**.
3. В окне выбрать образец — нужный лист (или таблицу) → ОК. Откроется редактор Power Query со всеми строками из всех файлов;
   столбец `Source.Name` — из какого файла строка (полезно оставить).
4. Проверить типы столбцов (значок слева от заголовка: 123 — число, календарь — дата, ABC — текст), исправить при необходимости.
5. Убрать мусор: Главная → Удалить строки → Удалить пустые строки; фильтр по столбцу → снять «Итого».
6. **Главная → Закрыть и загрузить** — на новом листе появится общая таблица.
7. В следующем месяце: положить новые файлы в ту же папку → **Данные → Обновить все**.

Группировка прямо в Power Query (вместо отдельной сводной): перед шагом 6 — **Главная → Группировать по** → «Подробнее» →
столбцы группировки (например, Контрагент и Месяц) → новые столбцы: «Сумма» по «Сумма», «Количество строк» и т.п.

## Способ 2. Power Query: листы одной книги или разные таблицы
1. Каждый диапазон превратить в таблицу: щёлкнуть в данных → Ctrl+T → «Таблица с заголовками».
2. Для каждой: **Данные → Из таблицы/диапазона** → в редакторе **Главная → Закрыть и загрузить в… → Только создать подключение**.
3. **Данные → Получить данные → Объединить запросы → Добавить** → «Три таблицы и больше» → выбрать все → ОК.
4. При необходимости «Группировать по» (как в способе 1) → Закрыть и загрузить.
«Добавить» — это строки одна под другой. «Слияние» — это соединение по ключу (как ВПР), см. способ 5.

## Способ 3. Сводная таблица (итоги по группам)
1. Щёлкнуть в общей таблице → **Вставка → Сводная таблица** → «На новый лист».
2. Поля: в «Строки» — по чему группировать (Контрагент), в «Столбцы» — при необходимости (Месяц),
   в «Значения» — что считать (Сумма; щёлкнуть → «Параметры полей значений» → Сумма / Количество / Среднее).
3. Даты по месяцам: правой кнопкой по дате в сводной → «Группировать» → Месяцы и Годы.
4. После изменения данных: правой кнопкой по сводной → «Обновить».

## Способ 4. Формулы итогов
Классические (любая версия, разделитель аргументов в русском Excel — `;`):
- Сумма по условию: `=СУММЕСЛИМН(Таблица1[Сумма];Таблица1[Контрагент];"Ромашка")`
- Сумма за месяц: `=СУММЕСЛИМН(Таблица1[Сумма];Таблица1[Дата];">="&ДАТА(2026;10;1);Таблица1[Дата];"<"&ДАТА(2026;11;1))`
- Количество: `=СЧЁТЕСЛИМН(Таблица1[Контрагент];"Ромашка")`
- Список уникальных значений (365/2021): `=УНИК(Таблица1[Контрагент])`, рядом — СУММЕСЛИМН по нему.

Excel 365 (новые функции; в русской версии имя функции может быть переведено — начать вводить и выбрать из подсказки):
- Сложить несколько диапазонов в один: `=VSTACK(Лист1!A2:D100;Лист2!A2:D100)`
- Группировка с итогом одной формулой: `=GROUPBY(Таблица1[Контрагент];Таблица1[Сумма];SUM)`
- Сводная одной формулой: `=PIVOTBY(Таблица1[Контрагент];Таблица1[Месяц];Таблица1[Сумма];SUM)`

## Способ 5. Сопоставить два списка
- Подтянуть значение: `=ПРОСМОТРX(A2;Лист2!A:A;Лист2!C:C;"нет")` (365/2021), в старых версиях
  `=ЕСЛИОШИБКА(ВПР(A2;Лист2!A:C;3;ЛОЖЬ);"нет")`.
- Есть ли строка во втором списке: `=ЕСЛИ(СЧЁТЕСЛИ(Лист2!A:A;A2)>0;"есть";"нет")` → отфильтровать «нет».
- Расхождение сумм: подтянуть сумму из второго списка и `=B2-D2`, фильтр ≠ 0.
- Большие списки, повторяющаяся сверка — Power Query: **Данные → Получить данные → Объединить запросы → Слияние**,
  ключевой столбец в обеих таблицах, вид соединения «Внешнее левое» (все из первой + найденное во второй)
  или «Анти-соединение» (только те, кого нет во второй).
Ключ сверки должен быть одинаковым: ИНН лучше названия; у текстовых ключей убрать пробелы и привести регистр.

## Способ 6. Объединение прямо в чате
Если таблицы небольшие: пользователь вставляет их в чат (копировать из Excel → вставить) или прикрепляет файлы.
Агент:
1. Проверяет, что столбцы совпадают; если нет — показывает различия и спрашивает, как сопоставить.
2. Объединяет, при необходимости группирует и считает итоги.
3. Возвращает результат **таблицей Markdown** (копируется в Excel) или блоком CSV с разделителем `;`.
4. Отдельно пишет контрольные суммы: строк в каждом исходном файле и в результате, итоговая сумма по каждому
   файлу и в результате — чтобы пользователь сверил, что ничего не потерялось.
ФИО и другие персональные данные в таблицах в чате заменяются метками `<PERSON_1>` и т.п. и возвращаются в ответе
автоматически — метки в результате не менять и не объединять.

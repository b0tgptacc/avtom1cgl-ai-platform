# Проверка контрагента

Агент **не ходит в интернет**. Работа идёт так: агент даёт пользователю ссылки и что именно там смотреть →
пользователь открывает сервисы и вставляет в чат найденное (текст выписки, сведения, скриншот как текст) →
агент разбирает, отмечает признаки риска и пишет заключение.

Маскирование: ИНН организации (10 цифр) виден агенту как есть. ИНН ИП (12 цифр), ФИО руководителей и учредителей,
телефоны заменены метками `<…_N>` — это нормально, оценивать можно по фактам («руководитель — массовый»), а в ответе
система вернёт настоящие значения.

## Шаг 1. Что спросить у пользователя
ИНН (обязательно), предмет и сумма сделки, предоплата или отсрочка, разовая или длительная поставка.
Чем крупнее сумма и предоплата — тем глубже проверка (см. «Глубина»).

## Шаг 2. Сервисы и что смотреть (все бесплатные, официальные)
| Сервис | Ссылка | Что смотреть |
|---|---|---|
| Выписка ЕГРЮЛ/ЕГРИП (ФНС) | https://egrul.nalog.ru/ | статус (действующее / ликвидация / реорганизация / исключение), дата регистрации, руководитель и дата его назначения, учредители, адрес, уставный капитал, ОКВЭД, **записи о недостоверности сведений** |
| «Прозрачный бизнес» (ФНС) | https://pb.nalog.ru/ | массовый адрес / руководитель / учредитель, задолженность по налогам, непредставление отчётности, среднесписочная численность, уплаченные налоги, спецрежим, участие руководителя в других компаниях |
| Бухотчётность ГИР БО (ФНС) | https://bo.nalog.ru/ | выручка, прибыль/убыток, активы, капитал за 2–3 года; сопоставить с суммой сделки |
| Приостановление операций по счетам | https://service.nalog.ru/bi.do | действующие решения о блокировке счетов (нужны ИНН и БИК банка контрагента) |
| Задолженность и непредставление отчётности | https://service.nalog.ru/zd.do | долг по налогам свыше 1 000 руб. и отчётность, не сдаваемая более года |
| Дисквалифицированные лица | https://service.nalog.ru/disqualified.do | руководитель / юрлицо в реестре дисквалифицированных |
| Документы на госрегистрацию в работе | https://service.nalog.ru/uwsfind.do | готовящиеся изменения: смена руководителя, адреса, ликвидация |
| Реестр МСП | https://rmsp.nalog.ru/ | категория (микро/малое/среднее), численность — сверить с масштабом сделки |
| Картотека арбитражных дел | https://kad.arbitr.ru/ | дела как ответчика (взыскание долгов с него — тревожно), **банкротные дела**, суммы, свежесть |
| Банкротства (ЕФРСБ) | https://bankrot.fedresurs.ru/ | заявления и сообщения о банкротстве |
| Федресурс | https://fedresurs.ru/ | сообщения о намерении ликвидироваться, уменьшении капитала, лизинге, залогах |
| Исполнительные производства (ФССП) | https://fssp.gov.ru/iss/ip | открытые производства, суммы, «ст. 46 ч.1 п.3/4» (нет имущества — признак неплатёжеспособности) |
| Реестр недобросовестных поставщиков | https://zakupki.gov.ru/ (раздел «Реестр недобросовестных поставщиков») | включение в РНП по 44-ФЗ / 223-ФЗ |
| Реестр уведомлений о залоге | https://www.reestr-zalogov.ru/ | залог имущества, которое нам продают или передают |

Если в компании есть **1С с подпиской ИТС** — в карточке контрагента работает проверка по базе ФНС и сервис
«1СПАРК Риски» (индекс должной осмотрительности); платные агрегаторы — Контур.Фокус, СПАРК-Интерфакс — сводят
всё в один отчёт. Это быстрее, но первоисточник — сервисы ФНС выше.

## Шаг 3. Признаки риска
**Высокий (стоп-фактор — сделку не делать без решения руководства):**
- ликвидация, реорганизация, исключение из ЕГРЮЛ, банкротство (любая стадия);
- запись о недостоверности адреса / руководителя / учредителя;
- приостановление операций по счетам;
- дисквалифицированный руководитель;
- отчётность не сдаётся более года, нулевая выручка при крупной сделке;
- в РНП.

**Средний (нужны документы и обоснование выбора):**
- компания моложе 1 года; уставный капитал минимальный (10 000 руб.) при крупной предоплате;
- массовый адрес или руководитель (руководит 5+ компаниями) / руководитель = единственный учредитель и сотрудник;
- численность 0–1 человек при поставке, требующей склада, транспорта, персонала;
- налоговая задолженность; активные исполнительные производства; несколько свежих исков как к ответчику;
- недавняя смена руководителя / адреса / учредителя (за последние 3–6 мес.) или такие изменения в работе (uwsfind);
- ОКВЭД не соответствует предмету сделки; нет сайта, телефона, истории;
- реквизиты счёта или e-mail в письме не совпадают с прежними (риск мошенничества с подменой реквизитов — перезвонить по известному номеру).

**Низкий:** работает 3+ года, сдаёт отчётность, выручка соразмерна сделке, платит налоги, нет банкротных дел и блокировок.

## Шаг 4. Документы от контрагента (для должной осмотрительности)
Карточка предприятия с реквизитами; выписка ЕГРЮЛ (свежая, можно скачать самим); Устав (первые и последние листы);
решение/приказ о назначении руководителя; доверенность подписанта, если подписывает не руководитель; паспорт подписанта
(сверка ФИО) — без копии в чат; лицензии / СРО / сертификаты — если вид деятельности требует; бухотчётность за последний год;
подтверждение ресурсов (склад, транспорт, персонал) — для крупных поставок.

## Глубина проверки
| Ситуация | Что делать |
|---|---|
| Разовая покупка до ~100 тыс. руб. без предоплаты | ЕГРЮЛ + «Прозрачный бизнес» + блокировки счетов |
| Обычная поставка / услуги | всё из таблицы шага 2 + документы шага 4 |
| Крупная сделка, предоплата, новый контрагент, импорт | всё выше + личный контакт, проверка площадки/склада, платный отчёт (Фокус/СПАРК) |

## Шаг 5. Заключение (формат ответа)
```
Заключение о проверке контрагента
Контрагент: [наименование], ИНН [ИНН]. Дата проверки: [дата].
Сделка: [предмет], [сумма], [условия оплаты].

Проверено: [перечень сервисов с датой].
Результаты:
- Регистрация и статус: …
- Руководство и учредители: …
- Финансы и отчётность: …
- Налоги, блокировки счетов: …
- Суды, банкротство, ФССП: …
Признаки риска: [список с уровнем] / не выявлены.
Уровень риска: НИЗКИЙ / СРЕДНИЙ / ВЫСОКИЙ.
Рекомендация: заключать / заключать при условии (без предоплаты, с поручительством, после получения документов …) / не заключать.
Проверку провёл: [Фамилия И.О.]
```
Напомнить: выписки и скриншоты сервисов сохранить к договору с датой проверки — это доказательство должной
осмотрительности (ст. 54.1 НК РФ; письмо ФНС России от 10.03.2021 № БВ-4-7/3060@) при налоговой проверке.

## Чего не делать
- Не утверждать факты о компании, которых пользователь не вставил в чат: агент не видит сервисы сам.
- Не выдавать заключение «надёжный» по одной выписке ЕГРЮЛ.
- Не просить вставлять паспортные данные и копии паспортов — для проверки они не нужны.

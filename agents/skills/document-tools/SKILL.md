# Документы и OCR

Интернета нет, всё нужное установлено. Вложения сотрудника — в папке `uploads` (только чтение), результат — в `outbox`
и ссылкой `/agent-files/<движок>/<имя файла>` (см. правила работы). Картинки модели не передавай — шлюз их
отклоняет; текст со сканов и фото получай через OCR.

## Перевод файла — только командой translate-document

Не пиши свой код перевода документа и не пересоздавай документ: готовая команда сохраняет профессиональную вёрстку и layout — стили, заголовки, абзацы, таблицы с линиями, колонки, колонтитулы, выделение, нумерацию и pagination там, где это поддерживает исходный формат.

```bash
translate-document "uploads/<файл>" --to en        # en | ru | zh; результат — в outbox
```

| На входе | Что получится |
|---|---|
| DOCX | DOCX с той же вёрсткой (стили, таблицы, колонтитулы, жирные слова) + PDF |
| PDF с текстом | PDF, переведённый на месте (линии, колонки, таблицы, подписи на своих местах) + DOCX для правки |
| PDF-скан, фото (PNG, JPG, TIFF) | OCR, перевод на месте поверх скана + DOCX для правки |
| DOC, RTF, ODT | через DOCX, как выше |

- Команда сразу ставит асинхронное задание в утверждённый сервис и делает только короткий ограниченный опрос.
  Она не запускает модель перевода в процессе агента. Если перевод ещё идёт, верни сотруднику ссылку прогресса;
  не жди десятки минут и не запускай второй раз параллельно.
- В конце команда печатает ссылки на прогресс и уже готовые артефакты (DOCX/PDF/QA), а также `замечание:`.
  Передай их сотруднику как ссылки; предупреждение QA не называй успешным переводом.
- Юридическая терминология (shall → «обязуется», indemnify → «возместить потери» и т. п.) и маскирование
  персональных данных уже встроены в команду.
- Если сотрудник просит перевод текстом в чате (а не файлом) — переводи сам, файл не нужен.

## Проверка результата перед ответом
```bash
pdftotext -layout "outbox/<файл>.pdf" - | head -60        # текст на месте, не обрезан
python3 -c "import pymupdf,sys; d=pymupdf.open(sys.argv[1]); print(len(d), 'стр.')" "outbox/<файл>.pdf"
```
- Число страниц совпадает с оригиналом; суммы, даты, номера пунктов, реквизиты — как в оригинале.
- Если команда сообщила о непереведённых абзацах — назови их сотруднику, не скрывай.

## Текст и таблицы из документа (не перевод)
| Задача | Команда |
|---|---|
| текст PDF с сохранением колонок | `pdftotext -layout файл.pdf -` |
| таблицы из PDF | `pdfplumber`: `page.extract_tables()` |
| скан → PDF с текстовым слоем | `ocrmypdf -l rus+eng --force-ocr in.pdf out.pdf` (китайский: `-l chi_sim+eng`) |
| фото → текст | `tesseract фото.png - -l rus+eng` |
| DOCX → текст | `python-docx`: абзацы, таблицы, колонтитулы |
| DOCX, XLSX, PPTX → PDF | `soffice --headless --convert-to pdf --outdir outbox файл` |

Скан или текст: `python3 -c "import pymupdf,sys; d=pymupdf.open(sys.argv[1]); print(sum(len(p.get_text().strip()) for p in d))" файл.pdf`
— меньше ~50 символов на страницу означает скан.

## Excel
- ИНН, ОГРН, счета, коды — текстом: `pd.read_excel(f, dtype=str)`, иначе потеряются ведущие нули.
- Суммы — к числу явно: `pd.to_numeric(s.str.replace(",", ".").str.replace(" ", ""), errors="coerce")`.
- Итоги — `groupby(...).agg(...)`; результат — `to_excel` с листами «Данные» и «Итоги», заголовки жирным,
  ширина колонок по содержимому (`openpyxl`), числа с разделителями разрядов.
- Перед ответом сверь контрольную сумму: итог по всем строкам = сумма исходных файлов.
